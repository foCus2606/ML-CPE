# LAB 7 - CNN Cat Breed Classification

Dataset: Cat Breeds (same dataset used in the previous SVM LAB)

Selected classes:
- abyssinian
- cyprus
- lykoi
- donskoy
- chausie

Experiments:
- CNN_1, 10 epochs
- CNN_1, 20 epochs
- CNN_2, 10 epochs
- CNN_2, 20 epochs

Run:
1. Check `DATA_PATH` in `main.py`.
2. Run `python main.py`.
3. After training finishes, run `python test_cnn.py` for prediction samples.

The `outputs` folder will contain models, accuracy comparison, confusion matrices, training/validation accuracy and loss graphs, and prediction samples.
